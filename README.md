# 大型車対応 駐車場ファインダー

車幅2m近い大型車（アルファード、ハイエース、レクサスLX等）でも安心して停められる駐車場を、寸法・構造・距離・料金で素早く絞り込めるNext.js Webアプリ。

## なぜこのアプリ？

既存の駐車場検索は料金や距離が中心で、**「車幅2mで入る」「機械式は不可」** といった大型車ドライバーが本当に欲しい情報が弱い。本アプリは:

1. 車両寸法（幅・長・高・重）入力で**寸法を満たす駐車場だけ**を表示
2. 機械式・タワー式など**構造で除外**できる
3. **大型車視点タグ**（余裕あり/ギリギリ/詰まった等）をユーザー同士で共有
4. 一般情報・口コミ・写真・経路は **Google マップ埋め込み** に任せる

## 起動方法

```bash
npm run dev          # http://localhost:3000
```

## ディレクトリ構成

```
app/                 Next.js App Router
  page.tsx           一覧画面（Server Component）
  parking/[id]/      詳細画面（Google Maps + 大型車タグ）
components/          UI部品（フィルタ、カード、タグ投稿UI）
lib/                 純粋関数（filter, distance, geolocation, bigCarTags）
types/               型定義
data/parkings.json   サンプル駐車場データ（首都圏18件）
```

## 検証シナリオ

| # | 操作 | 期待結果 |
|---|---|---|
| 1 | 起動直後 | 「普通車」プリセット適用で全件表示 |
| 2 | 「大型(2m級)」プリセット押下 | 機械式・タワー式が除外され件数が大きく減る |
| 3 | 「機械式」チェックOFF | 該当4件が消える |
| 4 | 「現在地から探す」許可 | 各カードに距離km、距離順ソート有効 |
| 5 | 「現在地から探す」拒否 | 距離フィルタdisable、料金順にフォールバック |
| 6 | 車幅 230cm を入力 | 空状態メッセージ表示 |
| 7 | 並び替え「料金が安い順」 | 昇順で並び替え |
| 8 | カードの「詳細を見る」 | Google マップ埋め込みが表示される |
| 9 | 詳細ページで「余裕あり」投稿 | 集計バー +1、リロード後も維持、一覧カードにバッジ反映 |
| 10 | 同じタグを連続投稿 | 1日1票でしか加算されない |

## 制約・MVP範囲

- **データ**: サンプルJSON（首都圏18件、`data/parkings.json`）。実APIは `lib/parkings.ts` の `fetchParkings()` を差し替えれば組み込める
- **タグ保存**: ブラウザ `localStorage`。他ユーザーとは共有されない（後段で実DBに差し替え予定）
- **地図**: 一覧画面には地図なし（リスト型のみ）。詳細ページは Google マップ埋め込み（APIキー不要）
- **認証なし**
